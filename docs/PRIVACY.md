# Политика конфиденциальности Notifilter

Дата вступления в силу: 16 августа 2026 года.

Notifilter работает локально на устройстве. Для выполнения созданных
пользователем правил приложение получает от Android название пакета, заголовок и
доступные текстовые поля уведомлений, в том числе когда интерфейс Notifilter
закрыт.

- Содержимое всех полученных уведомлений используется в оперативной памяти для
  проверки регулярных выражений. Пока Notification Listener подключён, текущие
  уведомления также могут временно храниться в памяти процесса, чтобы редактор
  правила показывал совпадения среди push в системной шторке. Этот список
  очищается при отключении listener или завершении процесса и не записывается в
  базу, настройки, логи или аналитику.
- История выключена по умолчанию и включается только пользователем. Старое
  согласие на журнал скрытых уведомлений не включает новую историю
  автоматически. После включения заголовок и доступный текст новых уведомлений,
  package name, время и результат обработки сохраняются в локальной базе, если
  уведомление доступно для фильтрации и не совпало с исключением истории.
- Исключения истории могут охватывать целое приложение, совпадения регулярного
  выражения во всех приложениях или совпадения внутри выбранного приложения.
  При включении исключения прежние совпадающие записи удаляются. По умолчанию
  включено редактируемое глобальное исключение для отдельного блока из 4–6 цифр;
  оно может исключать не только одноразовые коды, но также годы, цены и номера.
- История ограничена 1000 записями. Записи старше 30 дней удаляются при следующем
  запуске приложения или сервиса либо при добавлении новой записи; поэтому это
  очистка при следующей активности приложения, а не гарантированное стирание
  ровно в момент истечения 30 дней.
- Системные, non-clearable, звонки, будильники, медиа, ongoing,
  foreground-service, group-summary, full-screen и собственные уведомления
  Notifilter в историю не записываются. Уведомления, обнаруженные только при
  чтении системной шторки для предпросмотра, сами по себе историю не создают.
- Данные не передаются разработчику или третьим лицам.
- В приложении нет рекламы, аналитики, crash-reporting и разрешения на интернет.
- Приложение запрашивает отключение Android backup и явно исключает базу,
  настройки и файлы из cloud backup и device-to-device transfer. Фактическое
  поведение переноса также зависит от реализации Android производителем.
- По явному действию пользователя приложение может создать резервную копию
  правил в выбранном через системный интерфейс JSON-документе. В нём находятся
  package name, регулярное выражение и параметры каждого правила; история,
  исключения истории, содержимое уведомлений, настройки и ключи подписи не
  экспортируются.
- Экспортированный JSON хранится у выбранного пользователем файлового
  провайдера. Если выбран облачный провайдер, он может передавать и хранить файл
  по собственной политике. Notifilter не сохраняет постоянный доступ к
  документу и не отправляет его самостоятельно.
- При импорте выбранный JSON временно читается в памяти, полностью проверяется и
  после подтверждения используется для локального обновления правил. Данные
  файла не добавляются в историю или аналитику.

Пользователь может в любой момент выключить историю или фильтрацию, удалить одну
запись, очистить историю, отозвать доступ в системных настройках Android либо
удалить все локальные данные, очистив хранилище/удалив приложение. Выключение
истории не удаляет прежние записи автоматически: для этого есть кнопка
«Очистить». Удаление записи убирает её из логической базы приложения; мгновенное
физическое перезаписывание блоков памяти устройства не гарантируется SQLite и
флеш-накопителем.

Экспортированный пользователем файл не удаляется при очистке данных или удалении
Notifilter. Его нужно удалить отдельно у выбранного файлового провайдера.

Вопросы о приватности можно задать через публичный трекер проекта:
https://github.com/nvprotas/notifilter/issues.
