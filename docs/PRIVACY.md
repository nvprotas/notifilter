# Политика конфиденциальности Notifilter

Дата вступления в силу: 30 июля 2026 года.

Notifilter работает локально на устройстве. Для выполнения созданных
пользователем правил приложение получает от Android название пакета, заголовок и
доступные текстовые поля уведомлений, в том числе когда интерфейс Notifilter
закрыт.

- Содержимое всех полученных уведомлений используется в оперативной памяти для
  проверки регулярных выражений.
- Журнал выключен по умолчанию и включается только пользователем. После
  включения видимые заголовок и основной текст уведомления, package name, время,
  сработавшее правило и статус запроса/подтверждения скрытия сохраняются в
  локальной базе приложения.
- Журнал ограничен 1000 записями. Записи старше 30 дней удаляются при следующем
  запуске приложения или сервиса либо при добавлении новой записи; поэтому это
  очистка при следующей активности приложения, а не гарантированное стирание
  ровно в момент истечения 30 дней.
- Разрешённые уведомления в журнал не записываются.
- Данные не передаются разработчику или третьим лицам.
- В приложении нет рекламы, аналитики, crash-reporting и разрешения на интернет.
- Приложение запрашивает отключение Android backup и явно исключает базу,
  настройки и файлы из cloud backup и device-to-device transfer. Фактическое
  поведение переноса также зависит от реализации Android производителем.

Пользователь может в любой момент выключить журнал или фильтрацию, удалить одну
запись, очистить журнал, отозвать доступ в системных настройках Android либо
удалить все локальные данные, очистив хранилище/удалив приложение. Выключение
журнала не удаляет прежние записи автоматически: для этого есть кнопка
«Очистить». Удаление записи убирает её из логической базы приложения; мгновенное
физическое перезаписывание блоков памяти устройства не гарантируется SQLite и
флеш-накопителем.

Вопросы о приватности можно задать через публичный трекер проекта:
https://github.com/nvprotas/notifilter/issues.
